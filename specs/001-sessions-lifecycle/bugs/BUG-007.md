# Bug Report: Unused Storage API and a Fixed Log Level

**Type**: Spec gap
**Severity**: Low
**Feature**: 001-sessions-lifecycle
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

`states.ListStates`, `users.List`, and the `states.State.Command` field are
never used (`Command` is always empty). The log level `DEBUG` and the text
format are fixed in `cmd/rideannouncer/main.go`, so production logs cannot
be quieter or structured. `README.md` does not document the configuration.

## Root Cause Analysis

The storage interfaces were written ahead of their use, and the log setup
was never made configurable.

## Recommended Fix

1. Remove `states.ListStates`, `users.List`, `states.State.Command`, and
   `states.CreateParams.Command`.
2. Read `RIDE_ANNOUNCER_LOG_LEVEL` (default `DEBUG`; changed to `INFO` on
   2026-11-16, task T046) and
   `RIDE_ANNOUNCER_LOG_FORMAT` (default `text`); pass them through Docker
   Compose.
3. Document the variables and running locally in `README.md`.
