# Bug Report: Session and User Operations Have No Tests of Their Own

**Type**: Untested flow
**Severity**: Medium
**Feature**: 001-sessions-lifecycle
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

`internal/ops/sessions.go`, `internal/ops/users.go`, `internal/models`, and
the `users`, `sessions`, and `states` repositories were exercised only
through `internal/service` tests. Constitution principle V requires tests for
behavior in `internal/`, and the Known Deviations list these packages.

## Artifact Traceability

### spec.md
- **Affected user story**: User Stories 1 and 2
- **Affected requirements**: FR-001 through FR-004
- **Gap identified**: Gap 6

### plan.md
- **Affected sections**: Constitution Check V, Technical Context (Testing)
- **Impact**: principle V passes for this feature

### tasks.md
- **Affected tasks**: T001–T007
- **False completions**: none
- **Missing tasks**: tests for each package

## Root Cause Analysis

The project tested behavior end to end through the service; the lower
layers never got their own tests.

## Recommended Fix

1. Repository tests (added with BUG-001 and BUG-003).
2. `ops` tests for users and sessions against in-memory repositories.
3. `models` tests for `State` and `NewSession`.
4. Narrow the constitution Known Deviation to the trip packages.
