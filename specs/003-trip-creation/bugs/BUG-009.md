# Bug Report: Creator Without a Username and Unlimited Trip Texts

**Type**: Spec gap
**Severity**: Low
**Feature**: 003-trip-creation
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

The trip card shows the creator as `@<username>`, so a user without a
username appears as a bare `@`. The name and the description accept any
text: only spaces, or text long enough to push the card past Telegram's
message limit.

Decision: show the creator's name when there is no username. The name must
have 1 to 100 characters and the description 1 to 1000, after trimming
spaces; anything else is asked again.

## Root Cause Analysis

The steps stored the raw message text, and the card assumed every user has
a username.

## Recommended Fix

1. `creatorName` in `internal/service/helper.go`.
2. `tripText` with `maxTripNameLen` and `maxTripDescriptionLen`; re-ask in
   `setTripName` and `setTripDescription`.
3. Tests: `TestCreatorName`, `TestTripText`, `TestService_TripTextLimits`.
