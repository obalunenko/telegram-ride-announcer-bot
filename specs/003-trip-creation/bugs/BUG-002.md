# Bug Report: Any Confirmation Answer Except `no` Publishes the Trip

**Type**: Spec gap
**Severity**: High
**Feature**: 003-trip-creation
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

At the confirmation step only the exact text `no` cancels; every other
answer publishes and pins the trip, including `No`, `nope`, a typo, or a
question. A trip can be announced in a group by accident.

Decision: `yes` publishes and `no` cancels, ignoring case and surrounding
spaces; any other answer gets "Please answer "yes" to publish the trip or
"no" to cancel it." with the same buttons, and the state stays
`StateNewTripConfirm`.

## Root Cause Analysis

`confirmTrip` treated `no` as the only special answer.

## Recommended Fix

1. Normalize the answer; publish on `yes`, cancel on `no`, ask again
   otherwise with `confirmKeyboard()`.
2. Test case-insensitive answers, an unclear answer, and an unclear answer
   followed by `yes`.
