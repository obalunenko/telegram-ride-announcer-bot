**Status**: Patched
**Patched**: 2026-11-15

## Description

`StateNewTripPublish` is declared and routed by `textHandler`, but no step
sets it and `createTrip` has no branch for it (constitution Known
Deviation). The comments in `createTrip` list steps that were never built: a
track link or file, a photo, and subscribing the creator. `textHandler` has
a dead `TODO: Handle commands.` branch, since commands never reach it.

Decision: remove the unused state, the routing, and the dead branch;
record the planned steps as out of scope for this feature, to be specified
as new features.

## Root Cause Analysis

The state list and the step comments were written for the planned dialog
and kept after the scope shrank.

## Recommended Fix

1. Remove `StateNewTripPublish` from `internal/models/models.go`, run
   `make codegen`, and remove it from `textHandler`.
2. Replace the planned-step comments with the built steps; remove the dead
   command branch in `textHandler`.
3. List the planned steps as out of scope in the spec; drop the last
   constitution Known Deviation.
