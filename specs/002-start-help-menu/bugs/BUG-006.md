# Bug Report: Bot Username Without `@` and No Short Description

**Type**: Spec gap
**Severity**: Low
**Feature**: 002-start-help-menu
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

The welcome and the help name the bot as `test_bot` instead of the
clickable `@test_bot`. The startup sync manages the name, description, and
menu, but not the short description shown on the bot's profile page and in
shared links. Everything is set for the default language only.

Decision: show the username with `@`; sync the short description like the
description. Localization is not a requirement, so the default language
stays the only one (recorded as an assumption, not fixed).

## Root Cause Analysis

The username was passed as returned by `getMe`, and the short description
was not part of the original profile sync.

## Recommended Fix

1. Pass `@<username>` to the welcome and help templates.
2. Read the short description in `NewBot`, add `WithShortDescription` and
   `maybeUpdateShortDescription`, and set it in `cmd/rideannouncer/main.go`.
3. Update the fake Bot API defaults and the startup call counts in tests.
