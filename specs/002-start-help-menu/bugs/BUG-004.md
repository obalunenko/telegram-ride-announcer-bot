# Bug Report: `/help` Can List a Stale Menu

**Type**: Implementation drift
**Severity**: Low
**Feature**: 002-start-help-menu
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

`/help` lists `bot.Commands()`, the commands registered in Telegram. When the
menu update on startup fails, that list is whatever was registered before,
not the commands the code declares, so `/help` can show removed commands and
miss new ones.

## Root Cause Analysis

The bot wrapper kept only the registered commands; the declared ones were
used once for the startup sync and dropped.

## Recommended Fix

1. Keep the declared commands in `telegram.Bot` and return their enabled
   part from `Menu()`, falling back to the registered commands when none are
   declared.
2. List `bot.Menu()` in `helpHandler`.
3. Test `Menu()` with and without declared commands and with a failed
   update.
