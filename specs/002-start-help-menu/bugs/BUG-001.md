# Bug Report: Welcome Message Promises Features That Do Not Exist

**Type**: Implementation drift
**Severity**: Medium
**Feature**: 002-start-help-menu
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

The `/start` welcome lists a list of upcoming trips, subscriptions, a list of
subscribed trips, and outfit and SPF recommendations based on the weather.
The first three are stubs; the weather recommendations do not exist at all.
`README.md` does not describe the commands either.

Decision: the welcome and the README describe only what the bot does today;
new items are added together with their features.

## Root Cause Analysis

The welcome was written for the planned product and never trimmed to the
built one.

## Recommended Fix

1. Rewrite `welcome.gotmpl` to list creating and announcing a trip and
   showing your trips; update `welcome.golden`.
2. Add a Commands section to `README.md`.
