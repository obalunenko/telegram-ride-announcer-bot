# Bug Report: Long `/mytrips` Lists Exceed the Telegram Message Limit

**Type**: Spec gap
**Severity**: Medium
**Feature**: 004-my-trips
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

All trip cards are joined into one message. A Telegram message holds at most
4096 UTF-16 code units, so a user with a few long trips (descriptions are up
to 1000 characters since 003 BUG-009) gets a failed `sendMessage` and no
list at all.

Decision: send the list in as many messages as needed; the header starts the
first one, and a card is never split.
