# Bug Report: `/mytrips` Lists Drafts

**Type**: Implementation drift
**Severity**: High
**Feature**: 004-my-trips
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

`/mytrips` lists every trip the user created that is not deleted, including
the draft of the current dialog, which may have an empty name. Since
003 BUG-001 published trips are marked completed, so drafts can be told
apart.

Decision: `/mytrips` lists only published trips.

## Root Cause Analysis

Drafts and published trips were indistinguishable (003 BUG-001), so the list
could not filter them.

## Recommended Fix

1. `publishedTrips` in `internal/service/mytrips.go`; `myTripsHandler`
   lists only its result.
2. Tests: `TestPublishedTrips`, `TestService_MyTripsHidesDrafts`; publish
   the trip in the render-failure case of `TestHandlers_Failure`.
