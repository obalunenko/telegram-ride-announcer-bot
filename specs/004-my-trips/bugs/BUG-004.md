# Bug Report: `/mytrips` Stays Silent When It Fails

**Type**: Spec gap
**Severity**: Low
**Feature**: 004-my-trips
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

When listing the trips or rendering a card fails, `/mytrips` logs the error
and sends nothing.

## Root Cause Analysis

There was no shared error reply until 001 BUG-002.

## Recommended Fix

1. Call `replyError` after logging both failures in `myTripsHandler`.
2. Assert the reply in the `/mytrips` cases of `TestHandlers_Failure`.
