**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

The trips come from iterating a map in the repository, so their order is
random and changes between calls. Since 003 BUG-004 every trip has a real
start, so the list can be ordered.

Decision: list trips by start, the nearest first; trips with the same start
keep the order in which they were created.
