# Bug Report: No Tests for Several Trips, Drafts, or Ordering

**Type**: Untested flow
**Severity**: Low
**Feature**: 004-my-trips
**Reported**: 2026-11-15
**Status**: Patched
**Patched**: 2026-11-15

## Description

The tests listed one published trip and an empty list. Nothing covered
several trips, drafts in the list, past trips, long lists, or the order, so
BUG-001 through BUG-003 went unnoticed.

### spec.md
- **Affected user story**: User Story 1 — List My Trips

- **Gap identified**: Gap 6

  levels

### tasks.md
- **Affected tasks**: T005
- **False completions**: none
- **Missing tasks**: an end-to-end ordering test

## Root Cause Analysis

The list was tested only as a side check of the trip dialog tests.

## Recommended Fix

1. Unit tests added with the fixes: `TestUpcomingTrips`, `TestSortByStart`,
   `TestSplitMessages`.
2. Handler tests: `TestMyTripsHandler_UpcomingOnly` (several trips, a draft,
   a past trip, order) and `TestMyTripsHandler_LongList`.
3. Service tests: `TestService_MyTripsHidesDrafts` and a new
   `TestService_MyTripsOrder` that publishes two trips in reverse order
   through the dialog.
